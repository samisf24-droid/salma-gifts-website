# موقع هدايا سلمى — salmagifts.com

موقع ثابت (HTML + CSS) مستضاف على GitHub Pages. كل النصوص مكتوبة داخل صفحات الـHTML مباشرة عشان جوجل وChatGPT وClaude يقدروا يقرأوها.

| `bakjat-katb-ktab/` | صفحة بكجات كتب الكتاب (البرواز، الأساسي، الشامل، الكتاب لحاله) |

## الطريقة الصح للتعديل

كل الصفحات بتنولد من ملف واحد: `_build/build.py`. عدّل هناك، وبعدين شغّل:

```
python3 _build/build.py
```

السكربت بيعيد كتابة كل الصفحات و`sitemap.xml` و`llms.txt`. **إذا عدّلت ملف HTML يدوياً، تعديلك بينمسح أول ما ينشغل السكربت.**

(أو ببساطة: احكي لClaude شو بدك تغيّر، وهو بيعدّل `build.py` وبيرفع.)

## تغيير سعر

كل الأسعار بمكان واحد بأول `_build/build.py`، بقاموس اسمه `PRICES`:

| المفتاح | المنتج | السعر الحالي |
|---|---|---|
| `masaka` | مسكة العروس | 18 |
| `taliqa` | تعليقة للمسكة (إضافة) | 2 |
| `saniya` | صينية الخطوبة / الدبل | 15 |
| `bakj_berwaz` | بكج البرواز | 20 |
| `bakj_asasi` | البكج الأساسي | 22 |
| `bakj_shamel` | البكج الشامل | 30 |
| `kitab` | كتاب / دفتر توقيع لحاله | 9 |
| `mahr` | صندوق المهر | 18 |
| `takharroj` | صينية التخرج | 13 |
| `stand`, `fanajin`, `qassasat`, `taqweem` | الإضافات | 2، 5، 3، 2 |

وأجرة التوصيل بمتغير `DELIVERY` (حالياً 2).

غيّر الرقم وشغّل السكربت: بيتغير السعر تلقائياً بكل مكان بيظهر فيه، وهي:
بطاقات الرئيسية، صفحة المنتج، جدول الأسعار بصفحة `tawseel`، الأسئلة الشائعة، البيانات المنظّمة (JSON-LD) اللي بيقرأها جوجل، العناوين والأوصاف، و`llms.txt`.

## إضافة صورة

1. حط الصورة بمجلد `assets/img/` بصيغة WebP، بمقاس 720×900 (نسبة 4:5)، واسم إنجليزي وصفي مثل `masaka-arous-red.webp`.
2. أضفها بقائمة الموديلات بالدالة المناسبة بـ`build.py` (مثلاً `models` داخل `build_masakat`) مع وصف عربي.

## إضافة منتج أو صفحة جديدة

1. أضف السعر لـ`PRICES`.
2. أضف الصفحة لـ`PAGES` و`NAV_ORDER`.
3. انسخ دالة صفحة شبيهة (مثلاً `build_mahr`) وعدّل نصوصها، وأضف استدعاءها بآخر الملف.
4. **لا تغيّر روابط الصفحات الموجودة** — تغييرها بيخسرنا ترتيب جوجل.

## تقييمات جوجل (لاحقاً)

لما يتفعّل ملف Google Business وتصير في تقييمات حقيقية، منضيف قسم «آراء الزبائن» بالرئيسية ورابط «قيّمونا على جوجل». **ممنوع تقييمات أو أسماء زبائن مخترعة**، ولا تضيف `aggregateRating` للبيانات المنظّمة إلا من تقييمات حقيقية.

## تحديث ملف التصميم

إذا عدّلت `style.css`، غيّر رقم `VERSION` بأول `build.py` وشغّل السكربت، عشان المتصفحات تجيب النسخة الجديدة.
